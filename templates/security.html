1. The Hybrid Cryptography Paradigm

In modern network security, neither symmetric cryptography nor asymmetric cryptography is sufficient on its own:

Symmetric Cryptography (AES-256)
  • Strength: Extremely high computational speed; hardware-accelerated via AES-NI instructions; optimal for bulk payloads.
  • Weakness: The "Key Exchange Problem" — how can two remote parties securely agree on a shared 256-bit secret without an eavesdropper intercepting it?
Asymmetric Cryptography (RSA-3072)
  • Strength: Solves key distribution. Public keys can be broadcast openly while only the holder of the private key can decrypt.
  • Weakness: Mathematically heavy modular exponentiations ($c = m^e \pmod n$); hundreds of times slower than AES; cannot encrypt large bulk files directly due to modulus size limits.
SecureLink Hybrid Solution: SecureLink uses AES-256-GCM to encrypt bulk file contents at blazing speed with authenticated integrity, and encapsulates only the small 256-bit AES key using RSA-3072 / OAEP.

2. Cryptographic Algorithm Specifications

Unlike legacy unauthenticated modes (such as CBC or ECB), AES-GCM provides both confidentiality and data authenticity simultaneously:

  • Key Size: 256 bits (32 bytes), offering $2^{256}$ keyspace, quantum-resistant against Grover's algorithm with an effective 128-bit quantum security level.
  • Nonce (IV): 96 bits (12 bytes) cryptographically random value per file transfer. Prevents replay attacks and identical ciphertext patterns.
  • GHASH Tag: 128-bit (16 bytes) authentication tag calculated using universal hashing over Galois Field $\text{GF}(2^{128})$. If even one bit is altered in ciphertext, the tag check fails during decryption.
  • Associated Data (AD): SecureLink binds the original filename as associated data, preventing filename spoofing attacks.

RSA relies on the mathematical difficulty of the Integer Factorization Problem of product $n = p \times q$:

  • Key Length: 3072 bits. According to NIST Special Publication 800-57, RSA-3072 provides 128 bits of security equivalent, compliant beyond 2030 (whereas RSA-2048 provides only 112 bits).
  • Public Exponent: Fixed at $e = 65537$ ($2^{16} + 1$), maximizing encryption speed while preventing Coppersmith low-exponent attacks.
  • OAEP Padding: SecureLink enforces RSA-OAEP with SHA-256 Mask Generation Function (MGF1). This renders the cipher IND-CCA2 secure (indistinguishable under adaptive chosen-ciphertext attacks), completely eliminating Bleichenbacher or PKCS#1 v1.5 padding oracle attacks.

5. Local Network & TLS Deployment Guide

To demonstrate multi-device transfer between two laptops or smartphones connected to the same college Wi-Fi:

  1. Find your machine's local IP address using ipconfig (e.g. 192.168.1.45).
  2. Run the Flask application bound to 0.0.0.0:5000.
  3. On Device 1, open http://192.168.1.45:5000 and register User A.
  4. On Device 2, open http://192.168.1.45:5000 and register User B.
  5. For encrypted TLS in transit, start Flask with ad-hoc SSL: python app.py --ssl or configure an Nginx / OpenSSL reverse proxy.
